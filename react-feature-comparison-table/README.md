# Feature comparison table with sticky columns React component

This table contains a feature comparison table of 4 fictitious Todo list products which is optimized for mobile and smaller screens. It will display in full when viewed on a desktop browser, but on narrow screens the 2 leftmost columns will stay in place while the user scrolls so that they can see side-by-side feature comparisons of the promoted product to its competitors.

This component showcases my ability to work with complex CSS and also to create an optimal user experience with the most utility.
